The look is kept on purpose: the Verifier scores how closely each app matches the original. What changes is everything underneath.

If you never used these programs, the new versions can look the same as the old ones, and that’s on purpose: the goal is a faithful copy, and the Verifier measures how close it is. What’s modernized is underneath. The original only runs on a thirty-year-old computer or an emulator; the new one runs in any browser. The code was in a dead language inside an undocumented file; now it’s readable JavaScript. The data is plain JSON anyone can use. A normal developer can change it. And documentation that never existed now does: a spec for each file format and a migration guide for each app. Think of it like remastering an old film into a digital format: it looks the same, but it isn’t stuck on film that’s falling apart anymore.
