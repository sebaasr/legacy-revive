Legacy IR

One shared JSON format between recovery and modernization. Every reader emits it; one web runtime renders it. A new program needs a reader and a translator, not a new app.

The project is five agents, each one a Claude Code subagent with its own role file. The Analyst reverse engineers the files from raw bytes. The Documenter turns its notes into one specification. The Clean-room Builder writes a reader using only that spec. The Modernizer turns the result into a web app and translates the old scripting language into JavaScript. The Verifier compares the new app with the original and sends defects back. The key design piece is the Legacy IR, a shared JSON format in the middle. It’s what makes the system general instead of a one-off HyperCard converter.
