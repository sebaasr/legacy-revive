What the agents could not do

Data that isn’t in the files

35 buttons use icons stored inside the HyperCard application, not the stack. They stay blank. Missing libraries were rebuilt from how scripts call them, and labelled as reconstructions.

Behavior isn’t a file format

Bytes say a ZZT lion is at (12, 4), not how it hunts. Engine rules came from the Modernizer’s knowledge, outside the clean room, and MIGRATION.md says so.

Measurement limits

ZZT references exist only for title screens, and its glyphs came from those same images, so 0.9999 is an upper bound.

Ethics

Only abandoned software or files whose license allows analysis. User-made files only; no original code copied into the output.

I want to be clear about the limits. Some data simply isn’t in the files: dozens of buttons use icons that live inside the HyperCard application, so they stay blank. Second, file formats can be recovered from bytes, but behavior can’t: the files say where a monster is, not how it moves. So the Modernizer used its own knowledge for game rules, and the migration notes say so. Third, my visual score for ZZT is an upper bound. And on ethics, I only analyzed user-made files whose licenses allow it.
