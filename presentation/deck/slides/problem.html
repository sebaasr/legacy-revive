Software disappears

When a platform dies, the programs people built on it go with it. Emulators keep some alive as museum pieces, but nobody can maintain or extend them.

1987 → 2004

HyperCard

Apple’s tool that let non-programmers build interactive “stacks”. Discontinued; thousands of stacks now run only in Mac emulators.

No docs · no source

Only the files survive

The file formats were never published. Recovering them takes reverse engineering, which today needs a human specialist.

The question

Can agents do it?

Recover how a program works from its files alone, and then modernize it, not just preserve it.

HyperCard is the example my professor gave me. Apple shipped it in 1987 and stopped selling it in 2004. People made thousands of stacks with it, and today they only run inside emulators. The file formats were never documented, so getting anything out of them means reverse engineering. My question was whether AI agents can do that work on their own, and then go one step further and modernize the software instead of only preserving it.
