This is the result I’m proudest of. HyperCard stores its pictures in a compressed format that Apple never documented. The Analyst worked it out from bytes alone: an opcode stream with seven different row filters. It checked each guess against screenshots of the original running in an emulator. The decoded pictures match 99.95 to 100 percent of the pixels in all ten stacks, and the only mismatch is a mouse cursor that happened to be in one screenshot. On ZZT, every file parses exactly to its last byte.
