Old scripts become readable JavaScript

HYPERTALK, 1990s

on mouseUp
put word 2 of the clickChunk into cr
put char (cr+1) div 2 of "AEPOZXLUGKISTVYN" after cd fld tcoda
end mouseUp

GENERATED JAVASCRIPT

// on mouseup
H.on(owner, "mouseup", async function mouseup($) {
// put word 2 of the clickchunk into cr
cr = H.chunk(H.f.clickChunk(), [["word", 2]]);
// put char (cr+1) div 2 of "AEP…" after cd fld tcoda
H.putInto(H.part($, "card", "field", "tcoda"),
H.chunk("AEP…", [["char", H.div(H.num(cr) + 1, 2)]]), "after");
});

One function per original handler, the original line kept as a comment above each translation. 18,385 of 18,403 lines translated (99.9%); the rest are counted, visible stubs.

The Modernizer doesn’t just redraw screens: it translates the programs. HyperTalk and ZZT-OOP each get a real parser that outputs JavaScript. I asked for readable output: every original handler becomes one function, and every original line stays as a comment above its translation, so a developer can see exactly what each line came from. Out of more than eighteen thousand lines, only eighteen couldn’t be translated, and those are visible stubs, not silent omissions.
